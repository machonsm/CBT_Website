# Sandra Machoń: Terapia CBT Online

The live website is a static, bilingual site for https://machoncbt.pl. Generated HTML runs without npm or API keys. Polish is at `/`; English is at `/en.html`.

After editing content or rendering in `static/site-content.js`, `static/app.js` or `static/cbt-model.js`, run `npm run build:seo` to refresh both HTML pages. They contain the same full content as the interactive page, so search engines and visitors do not need JavaScript to read it. Asset declarations in the `index.html` head are the shared source for both languages; the remaining HTML is generated by `scripts/build-seo.mjs`.

The repository root is the deployable website. For GitHub Pages, choose **Deploy from a branch → main → /(root)** in Settings → Pages; `.nojekyll` keeps the files unchanged. `npm run build` refreshes the generated pages and also creates an optional `dist` copy. Set `machoncbt.pl` under the GitHub Pages custom-domain setting, then point its DNS to GitHub Pages. GitHub Pages handles the domain redirect and HTTPS after configuration; an `/index.html` to `/` redirect is not configured by this repository.

SEO configuration (titles, descriptions, canonical URLs, hreflang, social previews, Person/WebSite/WebPage/Service structured data) is in `scripts/build-seo.mjs`. The sitemap includes the two language URLs and both legal pages, not section anchors. The legal-page source text is in `privacy-policy.md` and `terms-of-cooperation.md`; rebuild after editing either file. After deployment, verify the domain in Google Search Console, submit https://machoncbt.pl/sitemap.xml and inspect the URLs. Check live indexing and Core Web Vitals there; local checks cannot confirm search ranking or production performance. Do not add unconfirmed credentials, reviews, office addresses or medical claims to structured data.

GoatCounter is loaded on both language pages and both legal pages. Its endpoint is configured in `scripts/build-seo.mjs`; check the GoatCounter account settings against the published privacy policy before deployment.
